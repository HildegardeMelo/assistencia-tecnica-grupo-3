# 🛠️ TechFlix OS

https://techflix-os-g3.vercel.app/

> Plataforma web para gestão de Ordens de Serviço, acompanhamento de reparos em tempo real, emissão de orçamentos e notas fiscais, com conformidade legal de garantia.

## 📌 Sobre o Projeto

Este projeto foi desenvolvido para otimizar o fluxo de atendimento em assistências técnicas de computadores e celulares. O sistema abrange desde a triagem inicial via WhatsApp, registro de avarias com imagens na entrada, até o acompanhamento online pelo cliente, pagamentos e controle do prazo legal de garantia de 90 dias.

 ## 🎯 Funcionalidades Principais 

 - Triagem Inicial & Contato Agilizado: Envio de links de cadastro direto via WhatsApp para agilizar o atendimento presencial ou remoto. 
 - Cadastro Expresso para Serviços Rápidos: Fluxo simplificado para reparos rápidos (como troca de tela em 1h), coletando apenas os dados necessários para NF. 
 - Abertura de OS & Registro Fotográfico: Anexo de imagens do aparelho, check-list visual de avarias e aceite digital do cliente. 
 - Orçamento Interativo: Discriminação transparente de valores (mão de obra x peças), aviso sobre peças importadas e prazos. 
 - Acompanhamento e Notificações: Galeria com fotos do serviço concluído e atualizações sobre o progresso e entrega de peças.  
 - Checkout & Vitrine de Acessórios: Pagamento via link ou balcão, emissão de NF e sugestão de acessórios compatíveis com o modelo do cliente. 
 - Controle do Prazo Legal de Garantia: Consulta online garantida por 90 dias e arquivamento automático da OS após o 91º dia.
